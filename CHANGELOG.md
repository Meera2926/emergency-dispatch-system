# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-06-27
### Added
- START emergency medical triage decision engine and 110 BPM CPR audio-visual metronome.
- Dynamic 2D ray-casting polygon geofencing for real-time hazard perimeter warnings.
- Hospital capacity tracker and ICU bed-aware emergency triage router.
- Multi-agency coordinated dispatch (joint ambulance, fire, and police response).
- High-contrast accessibility themes and TalkBack / VoiceOver semantic labels.
- WebSocket real-time telemetry streaming client with heartbeat liveness watchdog.

## [1.1.0] - 2026-04-27
### Added
- Core architecture overhaul with functional `Result` and `Failure` hierarchy.
- Offline FIFO synchronization queue and exponential backoff retry interceptor.
- Haversine distance, bearing calculations, and polyline decoder utilities.
- Trilingual localization support for English, Hindi, and Tamil.
- Automated GitHub Actions CI workflow and CodeQL scanning.

## [1.0.0] - 2026-04-11
### Added
- Initial release of SafeCall SOS Emergency Resource Dispatch System.
